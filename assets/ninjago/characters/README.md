# Ninjago Tournament — playable 3D character models

This folder contains **10 real GLB models** from the user's
[LEGO Ninjago Tournament fan remake](https://github.com/yousseffekryk98-droid/LEGO-Ninjago-Tournament).

**Important:** These are original procedurally modeled and authored LEGO-style
approximations, **not** exact television-series meshes, original LEGO assets,
or output generated by TRELLIS.2. The source project contains the procedural
generation code; models are exported as standard glTF 2.0 binary files and
include named torso, head, arm, and leg nodes. They have no TRELLIS.2
inference dependency.

## Rebuild the models

The [import workflow](../../../.github/workflows/import-ninjago-character-assets.yml)
checks out a pinned revision of the game, regenerates the original character
GLBs, validates their meshes/joints and commits them to this fork's `main` branch.

The original generator is independent of TRELLIS.2; for actual **image-to-3D**
generation use [the TRELLIS.2 exporter](../../../tools/export_ninjago_character.py)
with a supported NVIDIA GPU and references you have permission to use.

## Usage

Load any `.glb` with a glTF 2.0-compatible viewer, Blender, or Three.js.
The game itself uses `public/assets/models/fighters/variants` paths. When
copying these into the game, preserve those paths or update its character
design catalog accordingly.
